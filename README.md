# Small Business AI Hub

A unified dashboard containing various AI tools designed for small business productivity.

## Features
* **AI Tool Dashboard**: A responsive grid containing entry points for multiple AI assistants.
* **Social Media Caption Generator**: Generate Instagram/Facebook captions and hashtags based on product names and features (mock UI implemented).
* **Future Expansion**: Placeholders for Reply Assistants, Invoice Extractors, FAQ Bots, and Lead Follow-ups.

## Platforms Supported
* Web
* iOS
* Android
* macOS
* Windows

## Setup
Run the app locally with:
```bash
flutter run
```
