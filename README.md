# Quick Notes

A beautiful, simple cross-platform notes application built with Flutter.

## Features
- Clean, modern interface
- Create, view, edit, and delete notes
- Notes persist in memory (ready for local storage integration)
- Fully responsive across Mobile, Web, and Desktop

## Running the App

```bash
flutter run
```
